# مسودة صفحة المتجر — للمراجعة قبل النشر

## اسم التطبيق

منشأة العمار

## الوصف المختصر

دليل خدمات منشأة العمار: ابحث عن الخدمة وتواصل مباشرة مع مقدمها.

## الوصف الكامل

منشأة العمار — بلدنا أقرب، دليل مجاني يساعد أهل منشأة العمار على الوصول إلى الخدمات والمهن والمحلات المحلية.

تصفح مجالات الخدمات، وابحث بالاسم أو نوع الخدمة أو المنطقة بين النتائج المحملة، وشاهد معلومات مقدم الخدمة وعنوانه. يمكنك فتح الاتصال أو واتساب عندما يضيف مقدم الخدمة رقمًا مناسبًا، أو نسخ رقم التواصل. يتم التواصل خارج التطبيق مباشرة.

تصفح الدليل دون حساب. لأصحاب الخدمات: أنشئ حسابًا مجانًا، وأرسل بيانات خدمتك للنشر، وتابع حالة طلباتك من «خدماتي». بيانات الخدمة لا تظهر للعامة إلا بعد الموافقة؛ والتعديلات تحتاج مراجعة قبل أن تحل محل المعلومات المنشورة.

التطبيق لا يقدم حجوزات أو مدفوعات أو محادثات داخلية ولا يضمن جودة الخدمة أو هوية مقدمها. نطاق الدليل منشأة العمار، وليس تغطية لكل المحافظات. البحث يغطي النتائج المحملة، وقد تحتاج لتحديثها والاتصال بالإنترنت.

## ملاحظات الإصدار الأول المقترحة

- البحث في دليل الخدمات المحلية حسب المجال والمنطقة.
- عرض بيانات الخدمات المنشورة والتواصل المباشر ونسخ الرقم.
- تسجيل حساب مقدم خدمة وإرسال طلبات الإضافة والتعديل للمراجعة.
- دعم العربية واتجاه العرض من اليمين لليسار والمظهر الفاتح والداكن.
